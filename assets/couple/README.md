# Couple cutouts

`gautam.png` and `priya.png` are transparent head-and-torso cutouts prepared from the two wedding portraits supplied in chat on November 21, 2026. Backgrounds and surrounding people were removed using the built-in image_gen tool. The generated alpha channels are preserved; the originals in chat are not overwritten.

The exact edit prompts are saved in [prompts.json](prompts.json). The scene draws each PNG separately in its original colors, using independent bounce states, with a pulse on the music beat. Both images are bundled for offline use.
